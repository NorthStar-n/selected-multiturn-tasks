# Catalog source quality notes

COD coverage is explicit only for selected per-element files in this package. Copper is covered by the Cu file, but the absence of another element's file is not evidence that a mixed compound is absent from COD.

OQMD stability is an energy-above-hull style computational field. PubChem canonicalization, SMILES, and InChI fields are identity descriptors and should not be treated as formation-energy or stability evidence.

Literature metadata in the open search pulls contains broad matches. Use DOI or title evidence before accepting a record as a property source for PCB conductor copper.

The AFLOW conductor slice includes a local A1 copper query snapshot because the broad catalog table is dominated by library prototypes and does not carry every elemental query result used by the lab's normal workflow.
